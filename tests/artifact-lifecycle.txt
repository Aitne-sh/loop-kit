# artifact-lifecycle.txt — every .loop/ path bin/loop.sh touches must be
# classified here, or the meta-lint test in run_tests.sh fails.
#
# Format: <path-prefix> <scope>   (first matching prefix wins; longest/specific
# entries go before general ones). Scopes and their reset boundaries:
#   run        — reset at every fresh run (cmd_run pre-routing block + FRESH list)
#   contract   — archived + reset when a NEW task is defined (reset_contract_scoped_docs);
#                fleet queue/plan entries are bound to the contract via
#                .loop/decompose-approved (check_fleet_contract_binding)
#   persistent — never reset (audit trail, approval records, user-owned inputs,
#                deployed harness pieces)
#   liveness   — pid/heartbeat/lock signals; owned by the running process,
#                removed by finish()/on_interrupt or reaped by liveness probes
#
# Adding a new artifact? Decide which boundary must clear it BEFORE adding it
# here — an artifact nobody resets is how stale-state bugs are born (a prior
# run's decision.html once opened in the middle of an unrelated task).
